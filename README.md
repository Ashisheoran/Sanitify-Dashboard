# 🚀 Sanitify Dashboard

**Interactive Data Quality Intelligence Platform built on top of Sanitify**

A modern, premium Streamlit dashboard that allows you to analyze, diagnose, and fix data quality issues in seconds.

---

## 🌐 Live Demo

👉 **Try it here:** https://sanitify.streamlit.app

---

## 📦 Core Library

This dashboard is powered by the Sanitify engine:

👉 https://github.com/Ashisheoran/sanitify
👉 `pip install sanitify`

---

## ✨ Features

* 📊 **Dataset Profiling**
  Analyze structure, types, missing values, and distributions

* ⚠️ **Quality Issue Detection**
  Automatically detect:

  * Missing data
  * Duplicates
  * Constant columns
  * High cardinality

* 📈 **Quality Score System**
  Get a clear, interpretable score for dataset health

* 🛠 **Smart Fix Suggestions**

  * Impute missing values
  * Drop useless columns
  * Remove duplicates

* ⚡ **Interactive Fix Application**
  Apply fixes directly from the UI

* 📤 **Export Reports**
  Download structured JSON reports
